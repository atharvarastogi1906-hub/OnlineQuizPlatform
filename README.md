# Online Quiz Platform (Java GUI Application)

A robust, desktop-based interactive Online Quiz Platform developed using Java Swing and JDBC, built for the GUVI & HCL Hackathon submission.

---

## 🚀 Project Overview
The Online Quiz Platform is designed to provide a seamless testing and evaluation environment for users and administrators. It features secure user authentication, role-based dashboards, real-time interactive quiz sessions with countdown timers, and instant score evaluation backed by a database connection.

---

## 🛠️ Tech Stack & Concepts Implemented
* **Language:** Java (JDK 25+)
* **GUI Framework:** Java Swing, AWT
* **Database Integration:** JDBC (Java Database Connectivity)
* **Core Java & OOPs Concepts:** 
  * Encapsulation, Inheritance, Polymorphism, and Interfaces.
  * Exception Handling for robust form validations and error management.
  * Collections Framework (`ArrayList`, `HashMap`) for dynamic question and user management.
  * Multithreading & Synchronization for real-time question timers.

---

## 📂 Project Architecture & Package Structure
The application follows a clean modular MVC design pattern:
* `src/gui`: Contains all the graphical user interface windows (`LoginFrame`, `ParticipantsDashboard`, `QuizFrame`, `ResultFrame`, `RoleSelectionFrame`).
* `src/model`: Contains data blueprint classes (`Question.java`, `Quiz.java`).
* `src/data`: Handles database connectivity and state management (`QuizData.java`).
* `src/main`: Application entry point (`Main.java`).

---

## ⚙️ How to Run the Project Locally
1. Clone this repository or download the ZIP file.
2. Open the project in **IntelliJ IDEA**.
3. Ensure the project JDK (Java Development Kit) is properly configured.
4. Navigate to `src/main/Main.java`.
5. Click the **Run** button (or press `Shift + F10`) to launch the application.
